### ✅ 검증 완료된 핵심 기술

**1. 실시간 위치 → 추상화 변환**
- 브라우저 Geolocation API로 좌표 수집
- Haversine 공식으로 목적지까지 직선 거리 계산
- 거리 → "도보 5분 남음", "약 2.3km 남음" 텍스트로 추상화
- 방향 → Bearing 계산 후 나침반 화살표(🧭)로 표시

**2. 실시간 멀티유저 동기화**
- Socket.io WebSocket으로 같은 방 멤버들 실시간 위치 동기화
- 방(room) 단위로 분리, 메모리에 저장 (DB 없이 PoC 진행)
- 본인 위치는 다른 멤버에게만 브로드캐스트 (자신 제외)

**3. 시간 트리거 자동 on/off**
- 약속 시간 기준 ±1시간에만 위치 공유 활성화
- 10초마다 시간 체크, 활성화 상태 자동 전환

### 🗺 카카오 지도 연동

**사용 API**
- 카카오 지도 JavaScript SDK (지도 표시)
- 카카오 로컬 API - 키워드 장소 검색

**왜 카카오인가?**
- 네이버 플레이스 API는 일반 개발자에게 비공개
- 카카오 로컬 API는 장소 검색, 카테고리 검색 모두 지원
- 지도 SDK + 로컬 API를 같은 키로 사용 가능
- 한국 장소 데이터 품질 우수

**구현 내용**
- 장소 키워드 검색 → 결과 리스트 표시
- 장소 선택 시 지도에 마커 표시 + 지도 중심 이동
- 선택된 장소 좌표를 약속 목적지로 서버에 저장

**트러블슈팅**
- 401 Unauthorized: 카카오 개발자 콘솔에서 JavaScript 키에 도메인 등록 필요
  - 플랫폼 키 → Default JS Key → JavaScript SDK 도메인에 `http://localhost:3000` 등록으로 해결
